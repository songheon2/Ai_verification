# Visualization 요소 요약

현재 AutoVerify 시각화는 **DPLL·Theory, Simplex, ReLU** 세 부분으로 구성된다.

## 주요 화면

| 요소 | 보여주는 내용 | 읽는 방법 |
|---|---|---|
| DPLL·Theory | 라운드별 시간·결과, Simplex 호출 수, 선택한 제약과 이론 솔버 결과의 연결 | 어느 라운드에서 시간이 오래 걸리고 충돌이 발생했는지 확인한다. |
| Simplex | 호출별 시간, 피벗 수, 호출 결과, 반복 선택된 경계 위반 변수 | 선형 제약을 맞추는 과정에서 작업이 집중되는 호출·변수를 확인한다. |
| ReLU realtime | 최근 시간 구간의 활성 분기 수와 뉴런별 분기 상태 | 빨간 농도는 누적 분기 시작 횟수, 파란 테두리는 현재 열린 분기를 나타낸다. |
| ReLU feedback heatmap | 레이어·뉴런별 누적 분기 시작 횟수 | 진할수록 해당 뉴런에서 분기가 자주 시작됐다. 뉴런의 활성값이나 오차 크기는 아니다. |
| ReLU feedback history | 실행 전체 시간에 따른 활성 분기 수 | 탐색 중 동시에 열려 있던 분기의 증가·감소를 확인한다. 누적 분기 횟수 그래프는 아니다. |
| ReLU search tree | 활성·비활성 분기의 부모·자식 관계와 가지별 판정 | SAT·UNSAT 모두 직접 발견한 지점과 결과를 받아 종료된 상위 가지를 구분한다. 마우스를 올리면 발견 지점과 백점프에 의한 생략 여부를 확인할 수 있다. |

ReLU 분기 이벤트의 `+`는 분기 시작, `-`는 해당 분기의 탐색 종료를 뜻한다.

탐색 트리의 `+`와 `−`는 각각 ReLU 활성·비활성 분기 조건을 나타낸다.
트리와 타임라인에서 SAT·UNSAT은 같은 규칙으로 표시한다.

| 구분 | SAT | UNSAT |
|---|---|---|
| 직접 발견 | 초록색 `SAT 발견` | 빨간색 `UNSAT 발견` |
| 하위 결과를 받거나 탐색을 생략해 종료 | `CLOSED (SAT)` | `CLOSED (UNSAT)` |
| 최종 판정 | `SAT` | `UNSAT` |

예를 들어 N10 → N20 → N30에서 해를 찾았다면 N30은 `SAT 발견`, N20은
`CLOSED (SAT)`, N10은 `SAT`이다.
상위 가지에 마우스를 올리면 실제 해 발견 지점도 확인할 수 있다. 해 발견 후
다른 가지를 추가 탐색하는 것이 아니라 같은 결과를 상위로 반환하는 과정이다.

CLOSED 표시는 부모가 `RUNNING`인지 여부에 관계없이 동일하다. 직접 발견한
지점의 `SAT 발견`·`UNSAT 발견`은 구분하며, CLOSED 노드에 마우스를 올리면
전달·생략 역할과 실제 발견 지점을 확인할 수 있다. 여러 하위 가지의 결과를
합쳤다면 모순 발견 지점도 여러 개일 수 있다. 새 실행에서는 솔버가 모순의
직접 발견·하위 결과 전달·탐색 생략을 로그에 기록한다.

`+`와 `−`는 서로 다른 조건의 가지이므로 차례로 검사한 양쪽에서 각각 모순을
직접 확인할 수 있다. 이 경우에는 둘 다 `UNSAT 발견`이며, 한쪽 결과를
재사용하거나 생략한 경우에만 해당 가지를 CLOSED로 표시한다.

전체 검증 결과는 상단 배지와 `result.json`에서 확인한다. `SAT`·`UNSAT`·
`UNKNOWN`·`TIMEOUT`의 결과 필터는 `최종 결과` 하나로 통일한다. 이 필터는
판정 종류에 관계없이 마지막 탐색 노드와 루트까지의 상위 경로 하나만 보여준다.
별도의 원인 추론이나 UNSAT 증명 가지 전체 선택은 하지 않는다. 실행 중에는
갱신된 마지막 탐색 경로를 같은 방식으로 보여준다. `SAT 발견`·`UNSAT 발견`은 직접 발견한
지점만, `CLOSED (SAT)`·`CLOSED (UNSAT)`은 하위 결과를 받거나 탐색을 생략해
닫힌 노드를 보여준다. `CLOSED 전체`는 두 CLOSED 결과를 함께 보여준다.
일반 결과·레이어·뉴런 필터는 일치하는 노드만 독립된 행으로 보여주며,
상위 노드는 포함하지 않는다. `최종 결과` 필터는 상위 경로를 연결해 보여준다.
ReLU 분기 전에 해를 찾으면 탐색 트리에 표시할 분기 노드는 없을 수 있다.

레이어·뉴런 번호를 모두 입력하고 바로 옆의 `상위 트리 찾기`를 누르면,
전체 트리에서 일치하는 탐색 노드와 루트까지의 상위 경로만 펼친다. 같은 뉴런이
+·- 또는 여러 가지에서 탐색됐다면 일치하는 모든 위치를 포함하고 공유하는
상위 노드는 한 번만 표시한다. 찾은 노드는 파란 테두리로 강조하며, 그 아래의
관련 없는 가지는 생성하지 않는다. 번호 입력란에서 Enter를 눌러도 실행한다.

하위 트리를 보고 있었다면 전체 트리 검색으로 전환하며, 결과 필터는 `모든 결과`로
바꾸고 자동 경로 추적은 끈다. 검색 조건과 경로는 실시간 갱신·새로고침에서 유지한다.
번호 입력이나 결과 필터를 바꾸면 일반 필터링으로 돌아가며, `루트만 보기`와
`최근 경로보기`로도 검색을 해제할 수 있다. 입력이 빠졌거나 일치하는 탐색 노드가
없으면 버튼 옆에 안내한다.

같은 입력란·테두리 안의 `서브 트리 찾기`는 입력한 뉴런과 일치하는 모든 노드를
시작점으로 각각의 하위 트리를 끝까지 펼친다. 상위·형제 가지는 제외하며,
검색 결과가 서로 포함되면 하위 노드를 중복 표시하지 않는다. 새 분기와 새 일치
노드도 실시간으로 반영한다. 직접 접은 상태·검색 조건은 새로고침 후에도 유지한다.
타임라인과 STABLE 목록도 검색한 하위 트리 범위로 한정한다. `전체 트리로 돌아가기`는
검색 전의 표시 범위·필터·스크롤을 복원한다. 입력이나 결과 필터를 바꾸면
일반 필터링으로 돌아간다.

## 선택한 가지의 트리 표시

각 노드의 `이 가지 보기`를 누르면 그 노드를 시작점으로 하위 트리만 표시한다.
상위·형제 가지의 화면 요소는 제거하고, 선택한 노드의 하위 분기는 끝까지 펼친다.
접혀 있던 가지나 상위 트리 찾기의 검색 대상에서도 하위 트리를 바로 볼 수 있다.
선택할 때 기존 결과·레이어·뉴런 필터와 상위 경로 검색을 해제하며, 이전에 저장된
범위의 접힘 상태로 덮어쓰지 않는다. 펼쳐진 노드는 클릭해서 개별적으로 접을 수 있다.
선택한 하위 트리에 이후 추가되는 분기도 실시간으로 끝까지 펼친다. 처음 선택할 때
자식이 없던 노드가 나중에 자식을 갖거나, 새 분기의 깊이가 늘어나도 자동으로 반영한다.
직접 접은 가지와 스크롤 위치는 유지하며, 자동 펼침과 접힘 상태는 새로고침 후에도
복원한다. `루트만 보기`나 `최근 경로보기`로 표시량을 줄이면 자동 전체 펼침은
중단하고, 선택 범위에서 `모두 펼치기`를 누르면 다시 켠다.
상단에 현재 노드와 하위 가지 수를 표시하며, `부모 가지 보기`와
`전체 트리로 돌아가기`로 범위를 넓힌다. 이전에 본 범위로 돌아가면 해당 범위의
펼침 상태·결과/레이어/뉴런 필터·스크롤 위치를 복원한다. 선택 범위와 복귀할
화면 상태는 새로고침 후에도 유지한다.

결과 필터·타임라인·STABLE 목록은 선택한 하위 트리 안의 기록만 보여준다.
`최종 결과` 필터는 선택한 시작 노드부터 그 범위의 마지막 탐색 노드까지 연결한다.
`최근 경로보기`와 `최근 경로 추적`도 선택 범위 안에서 동작하며, 범위 밖에
새 가지가 생겨도 선택이나 스크롤을 바꾸지 않는다. 상단 검증 결과와 경계 유도 등
전체 지표는 실행 전체를 기준으로 유지한다.

탐색 중 경계 유도나 피벗 경계 강화로 추가 확정된 뉴런은 해당 가지에
`STABLE N개` 배지로 표시한다. 가지의 SAT·UNSAT 판정 배지는 별도로 유지한다.
결과 필터에서 `STABLE`을 선택하면 추가 확정이 발생한 가지만 남긴다.
실제 분기하지 않은 stable 뉴런을 분기 노드로 추가하지는 않는다.

하단 `STABLE 확정 뉴런` 목록에서 추가 STABLE·초기 STABLE·전체를 골라 보고,
최근 확정순·레이어/뉴런순·STABLE 확정 노드순으로 정렬할 수 있다. 확정 노드순은
이론 라운드와 노드 번호의 오름차순이며, 같은 라운드의 ROOT를 먼저 표시한다. 확정 결과는
`활성(+)` 또는 `비활성(-)`으로 표시하며, 확정 기법과 ReLU 입력의 전후 경계도 보여준다.
`STABLE 확정 노드` 열의 `D1 · 노드 #28`은 이론 라운드 1에서 실제로 확정이
발생한 탐색 노드를 가리킨다. 이 ID는 분기 진입 순서로 부여한 트리의 `node.id`이며,
하나의 분할에서 +·- 자식이 공유하는 `Split #N`과 별개다. 확정 이벤트가 포함된
깊이와 시간 구간으로 자식 노드에 연결하며, 초기 루트에서 확정되면 `D1 · ROOT`로 표시한다.
위치 버튼을 누르면 그 가지까지 펼쳐 이동한다. 레이어·뉴런 필터도 적용하며,
한 번에 50건씩 표시한다. 필터·정렬·페이지·스크롤은 실시간 갱신에서 유지한다.

`탐색 완료 순서 타임라인`과 `STABLE 확정 뉴런`은 제목을 눌러 각각 접거나
펼칠 수 있다. 상단 `하단 패널 접기/펼치기` 버튼은 두 패널을 함께 조작한다.
접으면 제목만 표시하고 내부 목록의 갱신은 다음에 펼칠 때 반영한다. 접힘 상태와
목록의 정렬·스크롤 위치는 실시간 갱신과 같은 보고서의 새로고침에서도 유지한다.

이 목록은 가지별 확정 이력이다. 한 가지에서 stable이 된 뉴런이 다른 가지에서도
stable이라는 뜻은 아니며, 동일 뉴런이 다른 가지나 이론 라운드에서 다시 확정되면
별도 기록으로 남긴다. 상단 경계 유도 수치는 초기 경계 유도 결과를 나타낸다.
초기·탐색 중·피벗 이후의 확정은 `reluplex_stable` trace와 분기 로그의
`relu_stable` 레코드에 기록한다. 이전 로그에는 이 정보가 없어 목록에 나타나지 않는다.

처음에는 루트 노드만 표시한다. 노드에는 현재 상태와 전체 하위 가지 수가
표시되며, 클릭하면 바로 아래 자식만 생성한다. 접으면 하위 화면 요소를 제거하고,
다시 펼치면 이전에 펼쳐 두었던 하위 위치를 복원한다. `루트만 보기`는 펼침
기억을 초기화하고, `모두 펼치기`는 현재 필터에 맞는 트리를 끝까지 펼친다.

트리는 상단 조작 영역 높이를 고려해 화면 높이의 60%(최대 640px) 안에서 커지고, 넘치는 내용은 트리 영역
안에서 위아래·좌우로 스크롤한다. 깊은 트리는 들여쓰기를 줄여 표시하며,
페이지 전체의 가로 폭은 늘리지 않는다. 실시간 갱신과 새로고침에서 트리 내부의
가로·세로 스크롤 위치를 복원한다. `루트만 보기`와 필터 변경은 내부 스크롤을
처음으로 돌린다. 위치 보기 버튼은 대상 노드를 트리 영역 안으로 이동한다.

실시간 갱신에서 하위 가지 수가 늘면 아직 확인하지 않은 증가분을 초록색 배지로
누적해 표시한다. 예: `+2 하위 가지 122개`. 증가 없는 갱신에서도 유지하며,
해당 노드를 직접 클릭하면 그 노드와 루트까지 모든 상위 노드의 배지를 지운다.
하위·형제 노드의 배지는 유지한다. 이후 추가된 가지는 다시
`+1`부터 누적한다. 처음 불러온 기존 가지는 증가분에 포함하지 않는다.

`최근 경로보기`는 루트부터 가장 최근에 추가된 가지까지 펼치고 해당 경로를
강조한 뒤 마지막 가지로 이동한다. 이 버튼은 기존 펼침 상태를 정리하고 최신
경로에 필요한 상위 노드만 펼친다. 경로 밖의 CLOSED 등 다른 가지는 접힌
요약만 남겨 하위 트리를 생성하지 않는다. 필요한 경우 결과·레이어·뉴런 필터를 해제한다.
새 가지가 없는 갱신 뒤에도 마지막 추가 경로를 볼 수 있으며, 기존 보고서를
처음 열었을 때는 마지막 방문 가지를 사용한다. 버튼을 누르면 마지막 가지와
루트까지의 상위 경로에 있는 증가분도 함께 지운다.

`최근 경로 추적`은 자동 추적을 켜고 끄는 버튼이다. 켜면 현재 최신 경로를
보여주고, 이후 새 가지가 추가될 때마다 해당 경로를 펼쳐 강조한다.
대상 노드가 트리 영역 밖에 있을 때만 내부 스크롤을 필요한 만큼 이동하고,
이미 보이면 위치를 유지한다. 자동 추적은 페이지 전체의 스크롤을 바꾸지 않는다.
자동 추적에서는 사용자가 다른 곳에 펼쳐 둔 가지를 그대로 유지한다.
추적한 경로의 증가분은 함께 지우며, 새 가지가 없는 갱신에서는 스크롤을 유지한다.
버튼을 다시 누르면 추적을 끈다. 추적 상태는 화면을 새로 불러와도 유지하며,
검증이 종료되면 마지막 경로를 보여준 뒤 자동으로 끈다.

실시간 갱신은 보이는 트리 문서를 다시 불러오지 않고 숨겨진 스냅샷 로더로
최신 데이터를 받아 반영한다. 보이는 노드의 상태·개수 등 변경된 항목만 갱신하며,
펼침 상태와 트리·타임라인의 스크롤을 유지한다. 타임라인은 한 번에 50개씩
표시하고 이전·다음 버튼으로 나머지 기록을 확인한다. 종료 상태도 같은 화면에 반영한다.

출력 HTML은 JavaScript를 포함하므로 별도 서버 없이 파일로 열 수 있다.
트리·타임라인·STABLE 목록은 흰색 바탕과 어두운 글씨로 표시하며, 판정별 배지 색으로 상태를 구분한다.
전체 탐색 데이터와 로그는 계속 보관한다. 이 기능은 화면 요소 생성과 갱신을
줄이며, 로그 크기나 HTML에 포함된 전체 데이터 크기를 줄이는 기능은 아니다.

## 변수와 결과 해석

- `z`: ReLU 적용 전 값, `h`: ReLU 출력값, `ineq_slack`: 부등식을 표현하는 보조 변수다.
- Simplex의 **경계 위반**은 해당 변수값이 현재 하한·상한을 벗어난다는 뜻이다. `h = max(0, z)` 관계 위반은 별도의 ReLU 검사다.
- 반복 위반 그래프는 기록된 이벤트에서 선택된 변수의 빈도다. 상세 이벤트가 샘플링되므로 모든 위반의 정확한 총횟수는 아니다. 호출·피벗 총계는 종료 이벤트의 집계값을 사용한다.
- 개별 Simplex 호출의 SAT/UNSAT는 그 선형 문제의 결과다. 전체 신경망 검증의 최종 결과는 `result.json`에서 확인한다.
- `NUMERICAL_FAILURE`, `TIMEOUT` 등은 확정 UNSAT가 아닌 UNKNOWN 사유다. 최근 추가했던 정확 유리수 검증과 수치 복구는 제거되었다.

그래프 하단의 수치 일관성 허용오차는 다음과 같다. 이는 기존 tableau 일관성 검사의 기준이며, 현재 최종 유리수 인증은 수행하지 않는다.

```text
|actual - expected| <= 1e-9 × max(1, |actual|, |expected|)
```

## 모드와 저장 파일

| 모드 | 동작 |
|---|---|
| 옵션 생략 (기본) | 시각화하지 않는다. |
| `realtime` | 실행 중 선택한 패널을 갱신한다. |
| `feedback` | 실행 후 전체 기록을 요약한다. |
| `both` | 두 기능을 함께 사용한다. DPLL·Theory와 Simplex PNG는 공유하며 중복 저장하지 않는다. |

기본 실행 폴더에는 모델·VNNLIB 사본과 `result.json`이 함께 저장된다. 아래 파일은 선택한 모드·패널에 따라 생성된다.

- `solver_*_dpll_theory.png`, `solver_*_simplex.png`: DPLL·Theory 및 Simplex 패널.
- `relu_realtime.png`: 실시간 ReLU 화면.
- `relu_feedback_heatmap.png`, `relu_feedback_history.png`: ReLU 사후 분석.
- `solver_progress.jsonl`, `solver_feedback.json`: 솔버 이벤트와 요약 데이터.
- `relu_events.jsonl`: ReLU 실시간 이벤트 기록. feedback-only는 메모리 기록을 사용하므로 생략될 수 있다.
- `*.html`: 선택한 실시간 패널을 한 화면에 표시하는 대시보드.
