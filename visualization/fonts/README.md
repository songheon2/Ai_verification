# Noto Sans KR

Bundled regular (400) and bold (700) TrueType files from Google Fonts, Noto Sans KR v40.
Used locally by HTML reports and Matplotlib; no runtime font downloads or OS installation.

- Source: https://github.com/google/fonts/tree/main/ofl/notosanskr
- Distribution: https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;700&display=swap
